# 居家睡眠呼吸初筛

该项目承载腕式睡眠采样批次、同步锚点、睡眠片段和报告版本。所有指数都应保留有效采样分母及质量上下文，报告内容仅用于初筛沟通。

领域结构位于 `src/contracts.ts`。`fixtures/overnight-stream.json` 包含设备时钟漂移、中途摘戴以及低灌注区间，时间均为脱敏数据。

项目使用 Node.js 22 和 TypeScript，`npm test` 会在严格模式下检查类型契约并运行全部单元测试。

## 核心原则：诚实呈现证据边界

初筛工具最常见的失败模式是"数据千疮百孔，指数却精确到小数点"。本模块反过来设计：

- **低灌注、信号丢失、数据缺口、降采样**的区间一律不参与指数计算，而是作为具体的
  **不可判读区间**（含起止时间与原因）呈现在报告里；
- **有效覆盖不足**（监测窗口 < 1 小时、有效血氧时长 < 4 小时或覆盖率 < 70%）时
  **不计算任何整夜指数**，只给出原因与复测建议；
- 指数的分母是**有效血氧监测时长**，不是"设备开了多久"；
- 每个指标都能追溯到使用的**批次、佩戴分段与算法版本**；
- 报告始终携带"非诊断结论"声明，并给出是否转正式检查的建议。

## 处理流程

1. **时钟校正**（`src/clock.ts`）：以单调设备时钟为准，用同步锚点做分段线性插值，
   吸收手机时钟漂移；锚点区间之外允许外推，但不确定度随距离增长并显式标记。
2. **夜次归组**（`src/nights.ts`、`src/timezone.ts`）：夜次按"正午 → 次日正午"划分，
   跨午夜睡眠、短暂清醒、半夜摘下再重戴都归入同一夜次。
3. **采样序列与佩戴分段**（`src/series.ts`）：批次拼接（重叠裁剪）、按间隔断裂分段，
   并提取不可判读区间的原始素材。
4. **候选事件识别**（`src/events.ts`）：血氧相对滚动基线下降 ≥3% 且持续 ≥10 秒记为
   候选事件；联合脉搏波（脉率上升）与体动（伪差标记）做交叉验证。
5. **质量门控**（`src/quality.ts`）：计算有效分母与覆盖率，决定夜次是否足以判读。
6. **报告与版本**（`src/report.ts`、`src/store.ts`）：每次生成都是新草稿；
   签署后的版本保持原样，后续补传或技师排除只产生新草稿版本。

## 运行

```bash
npm test              # 类型检查 + 构建 + 单元测试
npm start             # 分析 fixtures/overnight-stream.json 并演示版本流
node dist/src/cli.js 数据流.json --json
node dist/src/cli.js --exclude "2026-09-16T01:28:00+08:00,2026-09-16T02:06:00+08:00,离腕复测"
npm run generate:fixture   # 重新生成夹具（确定性，可复现）
```

CLI 会为每个夜次生成草稿 v1，随后演示：签署 v1 → 技师排除体动伪差区间 →
重新生成 v2 草稿，已签署版本保持原样。

## 报告内容

每份报告（`NightReportDetail`，扩展自 `contracts.ScreeningReport`）包含：

- **事件时间轴**：起止挂钟时间、谷值、下降幅度、脉率/体动交叉验证、可信度；
- **有效分母**：有效血氧分钟数 / 监测窗口分钟数与覆盖率；
- **不可判读区间**：低灌注、信号丢失、数据缺口、降采样、技师排除，各带原因；
- **质量说明**：重戴、短暂清醒、时钟外推、漂移校正等；
- **转诊建议**：基于初筛口径的每小时事件数分级（≥5 建议转正式检查，≥15 尽快）；
- **溯源**：每个指标对应的来源批次、分段与算法版本；
- **非诊断声明**。

## 目录结构

```
src/contracts.ts   领域契约（采样批次、同步锚点、报告骨架）
src/timezone.ts    时区工具与夜次（正午→正午）划分
src/clock.ts       单调时钟 + 锚点的挂钟校正
src/ingest.ts      数据流解析与校验
src/series.ts      采样序列、佩戴分段、不可判读区间
src/nights.ts      夜次归组与短暂清醒检测
src/events.ts      候选事件识别与交叉验证
src/quality.ts     有效分母与可判读性门控
src/analysis.ts    单夜分析编排
src/report.ts      报告明细与中文摘要
src/store.ts       草稿/签署版本存储
src/cli.ts         命令行入口
test/              node:test 单元测试与端到端测试
scripts/generate-fixture.mjs  夹具生成脚本
```
